# Laboratorio-de-Python---Trabajo-practico-integrador R
El repositorio incluye el codigo R que resuelve las consignas del TP integrador de MECAP. El trabajo fue realizado por Diego Sebastian López.

**Descripción del Proyecto**

El trabajo utiliza base de datos EDGAR de la SEC y busca responder para un grupo de empresas capital intensivas si los costos operativos son explicados por la antiguedad de los activos.

El objetivo de este proyecto es crear un dataset y utilizar técnicas de datos de panel para evaluar la pregunta plateada.

El desarrollo está dividido en tres ejes temáticos principales:
> Generacion del dataset.
> 
> Analisis exploratorio de datos.
> 
> Desarrollos de modelos de Datos de Panel.
